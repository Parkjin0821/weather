# 기상 데이터 및 공간정보 기반 전력설비 인근 화재 위험도 분석 방향 보고서

## 1. 문제 정의

본 프로젝트는 기상청 날씨 빅데이터 콘테스트의 **주제1: 기상 데이터 및 공간정보 기반 전력설비 인근 화재 위험도 분석**을 대상으로 한다. 핵심은 전신주 자체의 내부 고장만 예측하는 것이 아니라, **기상현상으로 인해 산불·화재 위험이 커지는 조건을 전력설비 위치와 결합해 설비 인근의 화재 위험도를 산정하는 것**이다.

따라서 분석 문제는 다음과 같이 정의한다.

- 예측 대상: 전력설비 인근 화재 발생 여부, 화재 발생 확률, 또는 위험 등급
- 공간 단위: 전신주/전력설비 좌표, 격자, 행정구역, 산림 인접권역
- 시간 단위: 일 단위 또는 시간 단위 기상 조건
- 주요 위험 요인: 고온, 저습, 강풍, 풍향, 무강수 지속, 누적 강수 부족, 낙뢰, 건조도, 산림/식생 인접성
- 전력설비 역할: 산불·화재 위험이 높은 공간에서 노출되는 설비 위치와 설비 특성을 반영하는 공간 기준점

초기 분석은 구조화 데이터에 강한 Random Forest, XGBoost/LightGBM을 중심으로 진행하고, 기상 시계열과 과거 화재 라벨이 충분해질 경우 LSTM 계열 모델을 확장 실험으로 둔다.

## 2. 데이터 설명

### 2.1 제공 데이터

기상청 콘테스트 분석 데이터 페이지 기준 주제1의 제공 데이터는 다음 두 축이다.

- 기상 데이터: 기온, 습도, 강수량, 풍속, 풍향, 낙뢰 등 기상 관측/예보 자료
- 전력 설비 데이터: 전신주 또는 배전설비 위치 및 설비 속성

본 프로젝트에서 `test_hanjeon.csv`는 전력설비 위치와 속성 데이터로 사용한다. 기상 데이터는 관측소 또는 격자 좌표와 시각 정보를 포함한다고 가정한다.

### 2.2 전력설비 데이터 활용 방향

전력설비 데이터는 화재 원인 그 자체라기보다 **화재 위험을 평가할 공간 단위**로 사용한다.

- 좌표: 설비별 위도/경도 또는 X/Y 좌표
- 설비 속성: 설비 종류, 설치연도, 전압, 선로 구분, 관리구역 등
- 공간 속성: 행정구역, 산림/초지/도로/주거지와의 거리, 설비 밀도

추가 공간정보를 확보할 수 있다면 산림 인접 여부, 토지피복, 경사도, 고도, 식생지수 등을 결합하는 것이 좋다.

### 2.3 기상 데이터 활용 방향

기상 데이터는 산불·화재 발생 가능성을 설명하는 핵심 입력 변수다.

- 기본 변수: 기온, 상대습도, 강수량, 풍속, 풍향
- 위험 변수: 최고기온, 최저습도, 최대순간풍속, 낙뢰, 일사량
- 파생 변수: 최근 24/72시간 누적 강수량, 무강수 지속일수, 평균 습도, 최대 풍속, 고온·저습 플래그
- 계절 변수: 월, 계절, 건조기 여부, 시간대

특히 산불 위험은 단일 시점의 기온보다 **고온·저습·강풍·무강수 지속의 조합**에서 커지므로, 누적·이동통계 피처가 중요하다.

### 2.4 데이터 결합 방향

전력설비 좌표와 기상 데이터는 좌표 기반 최근접 매칭 또는 격자 매칭으로 결합한다.

1. 전력설비 좌표와 기상 좌표의 좌표계를 통일한다.
2. 설비 좌표별 가장 가까운 기상 관측소 또는 격자를 찾는다.
3. 관측소까지의 거리를 피처로 남긴다.
4. 날짜/시간 기준으로 기상 값을 결합한다.
5. 화재 라벨이 있다면 동일 일자 또는 지정 반경 내 화재 발생 여부를 타깃으로 구성한다.

## 4. 모델 선정

### 4.1 추천 모델 비교

| 모델 | 장점 | 한계 | 적용 판단 |
|---|---|---|---|
| Random Forest | 소규모·중간 규모 구조화 데이터에서 안정적이고, 변수 중요도 해석이 쉽다. 결측과 이상치에 비교적 강하다. | 부스팅 모델보다 예측 성능이 낮을 수 있고, 희귀 화재 라벨에서는 확률 보정이 필요하다. | 1차 베이스라인과 변수 중요도 확인용 |
| XGBoost | 비선형 상호작용, 불균형 분류, 결측 처리에 강하다. SHAP 해석을 통해 위험 요인을 설명하기 좋다. | 하이퍼파라미터 튜닝과 시공간 검증 설계가 중요하다. | 최종 후보 모델 1순위 |
| LightGBM | 대용량·고차원 데이터에서 빠르고 성능이 좋다. 범주형/수치형 혼합 데이터에 효율적이다. | 데이터가 아주 작으면 과적합 관리가 필요하다. | XGBoost와 함께 주력 비교 모델 |
| LSTM | 시간 순서가 긴 기상 시계열을 직접 학습할 수 있다. | 라벨 수가 적거나 설비별 시계열이 짧으면 과적합 가능성이 크고 해석이 어렵다. | 충분한 시계열 확보 후 확장 실험 |

### 4.2 최종 권장 전략

1. **Random Forest**로 빠른 기준 성능과 주요 변수 중요도를 확인한다.
2. **XGBoost/LightGBM**을 주력 모델로 선정한다. 기상·공간·설비 속성의 비선형 조합을 잘 다루고, 산불/정전 위험 예측 연구에서도 트리 기반 모델이 널리 사용된다.
3. **LSTM**은 시간별 기상 데이터와 충분한 과거 화재 라벨이 확보된 뒤 비교 실험으로 수행한다.

평가 지표는 화재 라벨의 희소성을 고려해 Accuracy보다 **ROC-AUC, PR-AUC, Recall@K, F1-score**를 우선한다. 실제 대응 목적에서는 고위험 설비를 얼마나 잘 상위권에 올리는지가 중요하므로 Recall@K가 특히 유용하다.

## 5. 분석 파이프라인

### 5.1 데이터 로딩 및 EDA

- `test_hanjeon.csv` 행/열 수, 컬럼, 결측률, 좌표 범위 확인
- 기상 데이터 시간 범위, 관측소/격자 수, 변수별 결측률 확인
- 화재 라벨이 있다면 월별, 지역별, 기상 조건별 발생 분포 확인

### 5.2 전처리

- 좌표 컬럼 표준화: `asset_lat`, `asset_lon`, `weather_lat`, `weather_lon`
- 전력설비와 기상 관측소/격자 최근접 매칭
- 날짜/시간 기준 기상 데이터 결합
- 범주형 변수 인코딩, 수치형 결측 보간
- 화재 발생일 이후 정보가 학습에 들어가지 않도록 데이터 누수 점검

### 5.3 피처 엔지니어링

- 기상 피처: 기온, 습도, 강수량, 풍속, 풍향, 낙뢰
- 건조 피처: 무강수 지속일수, 최근 누적 강수량, 평균 습도, 최고기온
- 위험 플래그: 고온·저습, 강풍, 낙뢰 발생, 건조기
- 공간 피처: 위도, 경도, 관측소까지 거리, 행정구역, 산림/초지 인접성
- 설비 피처: 설비 종류, 설치연수, 선로 구분, 지역별 설비 밀도

### 5.4 학습 및 검증

- 베이스라인: Random Forest
- 주력 모델: XGBoost, LightGBM
- 검증 방식: 무작위 분할 + 시간 기반 분할 + 가능하면 지역 기반 분할
- 불균형 대응: class weight, scale_pos_weight, undersampling/oversampling
- 해석: permutation importance, SHAP, 위험도 상위 설비/지역 분석

### 5.5 제출 및 결과 활용

- 전력설비별 또는 격자별 화재 위험 확률 산출
- 위험 등급: 낮음, 보통, 높음, 매우 높음
- 고위험 설비 목록 및 지역별 위험도 지도 작성
- 주요 위험 조건 설명: 예) 최근 무강수, 저습, 강풍, 산림 인접성
- 검증시스템 제출 형식이 확정되면 예측 결과 컬럼명과 파일 포맷을 해당 공지에 맞춰 조정
